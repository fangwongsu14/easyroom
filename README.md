# 🏫 EasyRoom
## ระบบจองห้องเรียนออนไลน์

ระบบจองห้องเรียนออนไลน์ (EasyRoom) เป็นโครงงานปลายภาค
จัดทำขึ้นเพื่อช่วยอำนวยความสะดวกในการตรวจสอบห้องเรียนว่าง
และการจองห้องเรียนผ่านระบบออนไลน์

---

## 📌 ปัญหาและที่มา

ปัจจุบันนักศึกษาอาจไม่ทราบว่าห้องเรียนห้องใดว่าง
หรือมีการใช้งานอยู่ ทำให้ต้องเดินไปตรวจสอบหน้าห้องเรียน
เพื่อดูว่าห้องว่างหรือไม่

ปัญหาดังกล่าวอาจทำให้เกิดความไม่สะดวก
และอาจเกิดปัญหาการจองห้องเรียนซ้ำกัน

ดังนั้นจึงพัฒนาระบบ **EasyRoom**
เพื่อให้ผู้ใช้งานสามารถตรวจสอบห้องว่าง
และทำรายการจองห้องเรียนผ่านระบบออนไลน์ได้

---

## 👥 ผู้ใช้งานระบบ

ระบบแบ่งผู้ใช้งานออกเป็น 3 ระดับ

### 👨‍🎓 นักศึกษา (Student)

- สมัครสมาชิก
- เข้าสู่ระบบ
- ดูห้องว่าง
- จองห้องเรียน
- ยกเลิกการจอง
- ดูประวัติการจอง

### 👨‍🏫 อาจารย์ (Teacher)

- สมัครสมาชิก
- เข้าสู่ระบบ
- จองห้อง
- ดูตารางการใช้ห้อง
- ยืนยันการจองห้อง

### 👨‍💼 ผู้ดูแลระบบ (Admin)

- เพิ่ม / ลบห้อง
- เพิ่มอาคาร
- เพิ่มประเภทห้อง
- อนุมัติการจอง
- ดูรายงาน
- จัดการผู้ใช้งานทั้งหมด

---

## ⚙️ ฟังก์ชันหลักของระบบ

ระบบ EasyRoom ประกอบด้วยฟังก์ชันหลัก ได้แก่

1. สมัครสมาชิก
2. เข้าสู่ระบบ (Login)
3. ดูห้องว่าง
4. จองห้องเรียน
5. ยกเลิกการจอง
6. ดูประวัติการจอง
7. ดูตารางการใช้ห้อง
8. อนุมัติการจอง
9. จัดการข้อมูลผู้ใช้งาน
10. จัดการข้อมูลห้องเรียน
11. จัดการข้อมูลอาคาร
12. ดูรายการจองทั้งหมด
13. ดูรายงานการใช้งานห้อง

---

## 🗄️ โครงสร้างข้อมูล (Database)

ระบบมีข้อมูลหลักที่ต้องจัดเก็บ ดังนี้

### 👤 Users

ข้อมูลผู้ใช้งานระบบ

- ข้อมูลผู้ใช้งาน
- สิทธิ์การใช้งาน

### 🏢 Buildings

ข้อมูลอาคาร

- ชื่ออาคาร

### 🚪 Rooms

ข้อมูลห้องเรียน

- ชื่อห้อง
- อาคาร
- สถานะห้อง

### 📅 Bookings

ข้อมูลการจองห้อง

- ผู้จอง
- วันที่
- เวลา
- สถานะการจอง
